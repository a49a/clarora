# Clarora 桌面客户端

Clarora 的主桌面客户端，使用 GPUI 原生窗口和 Rust 业务代码，面向 macOS、Windows。React Native 版本保留在 `clarora-app/`，对应发行标注 RN。主版本应用与安装包统一显示 Clarora；当前验证范围和发行状态以对应构建记录为准。

## 启动

在仓库根目录直接使用 Cargo 启动；可在命令末尾加 `-- --data-dir /absolute/path` 指定测试目录。macOS 裸二进制不包含应用图标资源，需要 Dock 图标时使用下方原生打包脚本生成 `.app`；Windows 也可使用下方 PowerShell 构建方法。

```sh
cargo run --manifest-path clarora-gpui/Cargo.toml --locked
```

需要 Rust 1.93.1。macOS 需要 Xcode Command Line Tools；Windows 使用 Rust MSVC 工具链、Visual Studio 2022 的 C++ 桌面开发工作负载与 Windows SDK。

macOS 媒体工具：

```sh
brew install mpv ffmpeg yt-dlp
sh clarora-gpui/scripts/package-macos.sh
python3 clarora-gpui/scripts/install-pdfium.py clarora-gpui/target/Clarora.app/Contents/MacOS
codesign --force --deep --sign - clarora-gpui/target/Clarora.app
open clarora-gpui/target/Clarora.app
```

以上命令生成本机调试 `.app`，依赖开发机安装的 `libmpv`、FFmpeg、yt-dlp。包含运行库的 release ZIP／DMG 使用独立的[安装包流程](scripts/PACKAGING.md)，也可通过 `package-macos.sh --release` 转入该流程。Intel Mac 需自行提供并验证匹配架构的全部运行库；现有 PDFium 下载脚本仅包含 Apple Silicon 和 Windows x64 的固定版本及 SHA-256。

Windows PowerShell：

```powershell
./clarora-gpui/scripts/build-windows.ps1
python ./clarora-gpui/scripts/install-pdfium.py ./clarora-gpui/target/package
./clarora-gpui/target/package/clarora-gpui.exe
```

将匹配架构的 `mpv-2.dll` 及其依赖放在 EXE 旁；将 `ffmpeg.exe`、`ffprobe.exe`、`yt-dlp.exe` 放在 EXE 旁的 `tools/`，或加入 PATH。Windows 程序是普通桌面 EXE，不使用现有 React Native Windows 的 UWP 下载伴随进程。两平台共享下载实现；进程组取消分别使用 Unix 进程组、Windows Job Object。

完整 Windows 分发使用 `prepare-windows-runtime.ps1` 和 `build-windows.ps1 -Distribution -Installer`，收齐工具、ASR／TTS、PDFium、DLL 和许可证后生成 ZIP 与按用户安装的安装器。详细参数与验证命令见[安装包流程](scripts/PACKAGING.md)。分发包只加载包内运行库，不借用开发机 PATH；设置页的“运行环境”及 `--runtime-check /absolute/report.json` 可检查组件，后者不打开学习资料库。

## 界面与快捷操作

桌面界面采用暖灰与青绿色主题，导航按学习空间、资料库和个人工具分组。页面左上角可收起/展开左侧导航，也可按 `Cmd/Ctrl+B`；导航从左侧滑动展开/收起，内容区同步扩缩；按钮用加粗双箭头指示方向，并记住状态，重启后保留。侧栏底部可切换浅色/深色，也可按 `Cmd/Ctrl+Shift+L`。闪卡页默认聚焦学习卡片，点击“添加句子卡”展开编辑区；`Cmd/Ctrl+Shift+N` 可直接打开句子编辑并定位输入框。视频控制栏“字幕：开／关”控制画面字幕（含第二轨），普通／全屏共用并记住偏好；字幕列表保留供定位、复制和翻译。字幕页“导入英文字幕”加载 SRT／VTT，“英文生成中文”调用共用聊天 API 分批生成双语字幕，保留英文和时间轴，全部成功后才保存，失败／取消保留原缓存；已有中文不重复发送给模型。视频页采用左右工作台：左侧播放器，右侧“字幕／选集／AI 提问”页签；拖动中间分隔条调整宽度，窄窗口自动上下排列。字幕按正文长度展开，支持点击播放、逐句复制及提问；选集独立滚动，不再占用播放器下方空间。点击标题栏的 P 数可切到选集。字幕叠加在画面底部，可从控制栏“设置”菜单选择 14–32px 字号（默认 16px），立即生效并自动保存，普通与全屏播放共用；控制栏提供播放、前后 10 秒、进度拖动、倍速菜单、音量滑杆/静音；“设置”菜单集中管理字幕字号、循环方式和精听工具。选择“A–B 精听工具”展开起终点、清除、逐句切换、重听本句及片段闪卡；设置有效 A/B 后自动循环，进度条显示范围和金色边界，切换字幕句时退出旧循环。B 必须晚于 A；重设 A 超过旧 B 会清除旧 B。标题栏“更多”展开本地视频、bilibili 导入、字幕轨道、SRT 导出和最近视频；首次打开没有视频时自动显示。单击视频画面可播放／暂停，普通与全屏模式均支持；双击切换全屏后保持原播放状态。控制栏的“全屏”、双击视频画面或 `F11` 可进入视频专用原生全屏，`Esc` 或“退出全屏”返回；播放继续，退出后保留原导航/助手状态。

## 数据和使用

- 学习助手统一为全局右侧栏，所有学习栏目和视频全屏都可打开；`Cmd/Ctrl+J` 开关。拖选字幕、闪卡、电子书、写作输入或 AI 回复中的文字，点击选区旁的“问 AI”，先在侧栏查看完整原文，再输入问题或选择“解释用法／翻译成中文／举个例子”后发送。也可用 `Cmd/Ctrl+Shift+L` 呼出当前选区入口；PDF 页下方提供可选取的提取文字，扫描页需先完成识字。本轮不包含框选截图。
- 全局会话切换栏目时继续保留问题草稿、固定引用及正在生成的回答，不自动附带整篇当前资料。每次最多 4 份引用／120,000 字符，发送前可移除；无引用时仅发送问题和本会话历史。引用仅包含你选中的原文，不自动附加视频标题、文件名或模块名称；旧引用中的自动来源标签也不进入请求。对话区独立滚动，底部输入固定，可加宽侧栏；每条问题可展开查看当次实际引用，回复可复制或保存最新完整回答为问答卡。思考字段默认折叠，失败或停止时保留本次问题与引用，并标出未完成输出。历史入口可切回当前材料的旧会话。

- 专注倒计时固定显示在每个模块的页面顶部，滚动内容、收起导航或切换学习模块后仍可见，视频全屏同样显示。可直接开始、暂停、继续、重置，或通过“专注时长”选择 5–60 分钟并开始新一轮；与冥想页共用同一个计时器，专注结束后自动切换休息。计时不因切页重新开始，开始、暂停、继续和重置会立即保存到本机；退出或异常结束后重开，运行中的倒计时按实际经过时间恢复，暂停状态保留剩余时间。关闭期间已到期时只结算上一轮，并停在下一阶段等待继续，不自动累计离线多轮专注。
- 计划复习先按所选卡片类型筛选，再使用当天剩余新卡额度；额度按实际首次评分跨类型共享，翻看、切换类型、暂停或恢复未学卡不会消耗额度。“全部类型”按单词、句子、AI、音频片段、视频片段轮流安排新卡，首次评分后记住下一类型，重启后延续；已到期旧卡优先，非计划复习仍可自主学习。
- macOS 资料目录：`~/Library/Application Support/Clarora-GPUI/`；Windows：`%LOCALAPPDATA%\Clarora-GPUI\`。为兼容已有学习资料和凭证，资料目录及应用标识保持不变，无需手动迁移；使用独立 SQLite 和附件目录，可与 RN 版同时运行。
- 可通过 `--data-dir /absolute/path` 指定测试资料目录。不会自动打开或修改 RN 版数据库。
- 设置页可只读导入 RN 版 SQLite 快照、导入/导出 v2 ZIP 资料备份，或配置 S3/OSS。密钥默认保存于本机 SQLite，可选开启系统凭证库安全模式；应用导出的资料备份不包含密钥。
- 视频页支持本地视频、bilibili BV/av/完整地址及 `?p=` 分 P、取消下载、字幕主副轨、外部字幕、A/B、倍速和片段卡。需本机媒体工具，网络和视频可用性由视频来源决定。
- 切到其他栏目时，视频暂停并保存播放器的最新进度；返回视频学习时停在离开的位置，点击播放继续。切到音频或复习同一视频的片段后，返回时仍恢复完整视频的学习位置。
- 视频控制栏“重复模式”可选择无限重复或“每句重复三次 · 自动下一句”；字幕行也提供两个直接入口，普通和全屏模式共用。开启每句三次无需先点选字幕：按当前播放位置选择当前句，句间空白取下一条有效句，首句前取首句，字幕末尾取最后有效句；视频或字幕未就绪时先保留模式并暂停等待，字幕载入后自动开始，也可停止等待，不会自动调用转写或 AI。三次模式从选中句句首播放三遍，再自动进入下一条有效字幕并重新播放三遍，最后一句完成后暂停，不自动换集。该模式下 `←/→` 及上一句／下一句按钮按选中字幕切句，新句从第一遍开始；首尾不越界，暂停／继续保留遍数。无限模式只循环本句。视频普通窗口和全屏的 `←/→` 均跳到上一句／下一句字幕开头，暂停时切句仍暂停；当前句内按左定位上一句，字幕间隙则按方向寻找最近的有效字幕。无字幕时提示先生成或导入，首尾不越界，控制栏的前后 10 秒按钮继续按秒跳转。前后 10 秒跳转会退出重复。切换到其他模块会暂停并停止当前循环请求，但保留每句三次的选择，其他模块的播放／定位／循环不受影响；返回视频后恢复原位置所在字幕句的三次模式并保持暂停，继续时从该句第一遍计数。显式停止重复后，返回仍为普通模式。每句三次模式下点击或拖动音轨会保留当前重复句、范围、未完成的遍数及原播放／暂停状态：句内从点击位置精确定位，句外吸附到当前句最近的句首或句尾可播放位置，不切换字幕句。连续拖动采用最后选点，不再忽略同一句内的新位置；换句仍可使用左右键或字幕行的重复入口。最后一句已完成三次后再次定位，会从该句第一遍重新建立重复。已选“每句三次”时，切换视频或分 P 会保留模式，等新视频和字幕就绪后从目标起始句重新计数；原视频的循环范围不会沿用。没有字幕时暂停并显示“等待字幕”，生成或导入后继续；也可停止重复。此功能需要带时间轴的字幕；句尾超出视频时按实际视频长度截断。
- 视频最后一句按 `→` 会先暂停并提示下一 P，第一句（含句首前的空白）按 `←` 会提示上一 P；松开后再次按同一方向键才切换并播放。向左回上一视频时，从最后一条有效字幕开头播放；向右进入下一视频时，从第一条有效字幕开头播放。确认显示目标 P 编号／名称，长按产生的重复事件不会确认。按 `Esc`、点取消或按相反方向键可取消；反方向仍按原逻辑切相邻字幕。切页、换视频、重载字幕或手动跳转也会清除确认。普通／全屏和每句三次模式共用此操作；无字幕或整个选集首尾没有相邻 P 时只提示，不越界。`Cmd/Ctrl+Shift+←/→` 仍可直接切集。换 P 清除旧句循环范围，已选择的每句三次模式会在新视频字幕就绪后重新建立；准备期间的暂停选择会保留。
- 视频字幕可直接提问：生成字幕或加载 UTF-8 SRT / VTT 后，点“问当前句”“问整段字幕”，或某条字幕的“问 AI”，在右侧输入问题并发送。引用包含时间戳；当前句和指定行会暂停播放，并固定本次引用。引用加入全局会话，切换视频或分P不更换该对话；旧版按材料保存的会话可从助手历史入口查看，完整回答可存为问答卡。整段字幕超过 10,000 句或 120,000 字符时提示改用单句，不静默截断。内嵌字幕未解析为完整时间轴时只支持播放器当前句。使用设置中的共用 API；本地 Whisper / SenseVoice 仅负责转写，不负责问答。
- AI 设置提供一组共用 Base URL、模型 ID 和 API Key，供聊天与远端时间轴转写使用，保存后统一生效；模型需同时支持聊天与带时间轴转写接口。旧独立配置保存前保持原行为，旧版仅配置转写时表单沿用转写整组。视觉模型可单独选填，本地转写仍使用独立本地模型。全局侧栏保留最多 12 个全局会话，旧的按材料保存的会话仍可在历史入口访问，草稿随上下文保留，推理内容可展开。聊天流不受支持（HTTP 404/405）时回退一次非流式接口；断流、截断和模型错误不会保存为成功回答。
- 设置页“密钥存储”的安全模式默认关闭：AI 与对象存储密钥保存于 SQLite 的本机专用表，普通读取不会访问钥匙串。开启后迁移现有本机密钥到系统凭证库，成功后移除 SQLite 中的密钥记录；失败保留原模式与数据。关闭安全模式不会自动读取钥匙串；旧密钥可以重新输入保存，或主动点击“导入旧钥匙串密钥”授权一次迁移。SQLite 中密钥未额外加密，直接复制整个数据库文件会包含这些本机密钥；应用导出的资料备份不包含密钥。
- 密钥输入框不自动回填，API Key 留空保存会保留原引用。安全模式下按需读取并在进程内缓存；macOS 临时签名开发包首次访问仍可能要求系统授权。启动、播放和本地 ASR 只读取非敏感配置。
- 音频与视频的字幕列表开启“跟随”时，当前播放句按实际行高居中；调整窗口大小后重新定位。音频当前句卡片的原文逐行居中，中英文短句整体垂直居中，长句可滚动；拖选复制期间暂停自动定位。
- 音频学习对齐 RN 的阅读布局：顶部下拉选择练习组／音频并切换上一条、下一条，中间字幕独立滚动，底部集中波形、进度、播放、倍速和循环。每句右侧“复制”复制该句完整原文与译文，顶部“复制全部”按顺序复制全文（不含时间戳），不改变播放；盲听仅已翻开的句子显示复制按钮，且“仅中文”只复制中文。普通点击单词定位并播放；开启“截取片段”后，点击单词设置 A/B，Shift 点击扩展，拖动波形边界调整，按需编辑及保存闪卡。关闭截取会退出 A/B 循环。音频选择区下方单独显示字幕工具栏：“生成字幕”（已有字幕时为“重新生成字幕”）与“翻译成中文”直接点击，未选音频、无原文或任务忙碌时提供禁用原因。导入、刷新和当前句开关收进“更多”，字号放入带当前值的二级菜单，保留14–32px七档选择；盲听时只保留先退出盲听的“管理字幕”入口。工具栏在窄窗口换行；当前句参考 RN 独立卡片，使用绿色强调边、阴影、居中大号加粗原文和独立译文层级，显示时间范围与句序。长句限高并提供独立滚动条，切句回到文首；句间空白保留同高占位，盲听和关闭开关时不挂载卡片。“跟随”可关闭自动滚动。AI 标重点用下划线显示，悬停查看释义。词语时间按字幕字符长度估算，不代表声学逐词对齐。
- 音频学习顶部可切换“字幕／盲听”。盲听右键点击任意字幕行（包括词块）可翻看该句，再次右键收起；每句右侧也有“查看／收起”，可暂停并翻看指定句，遵循“仅中文／中英字幕”设置，不改变播放位置；继续后重新遮住。盲听原文按词显示遮挡块，点击词块会收起答案并从对应单词位置播放，点击时间戳或行空白从句首播放；词时间沿用普通字幕的字符偏移估算，并非声学对齐。若句首在 A/B 范围外则退出旧循环。盲听保留原字幕列表的时间戳、当前行高亮和跟随滚动，以遮挡条替代原文与译文，不挂载被隐藏的文字；隐藏重点和片段编辑，可回退 5 秒；“看刚才一句”先暂停并确认，再在原列表位置显示当前位置覆盖的单句字幕，句间空白取最近结束的一句，超过 10 秒提示“上一条字幕”。首句前或没有有效字幕时不揭晓，无字幕仍可播放。收起文字保持暂停，“继续盲听”自动隐藏并播放；播完可从头再听或查看全文（切回字幕模式并保持暂停）。播放、定位、切音频及字幕重载会清除揭晓；离开学习页、重启后回到字幕模式。AI 隐藏态只允许自由提问，揭晓态只引用当前已揭晓句，与普通字幕会话隔离。盲听操作栏“查看”可选“中英字幕／仅中文”，偏好自动保存。平时两种语言都遮挡；选“仅中文”后，点击“看中文”只显示刚才一句已有的中文，英文始终遮挡，继续播放后中文也重新遮住。无中文显示提示，中英混排行中的非汉字字母同样遮住，不回退到英文；AI 自动引用仅限已揭晓的中文。也可从 macOS／Windows 原生“听力”菜单操作。新增“从句首重听”、上一句／下一句，核对后重听会先隐藏答案；连续播放方式不变，完整 A/B 循环中仅跳转到范围内的完整字幕句。播放结束也能核对最后一句。页面聚焦时可按 `R` 从句首重听、`↑/↓` 前后换句、`H` 查看／收起文字、`C` 隐藏并继续，`Space` 播放／暂停；编辑输入框时不触发这些单键快捷操作。
- 口语分数表示识别文本对齐，包含漏读、读错、多读、完整度与语速。
- 本地转写支持 Whisper 模型和 SenseVoice。模型由设置页下载。点击“选用”后，模型行高亮并显示“已选择 · 待保存”；点击“保存 AI 与学习设置”成功后显示“已选用”和“当前生效”，重启后保留。Whisper 可使用 PATH 中的 `whisper-cli`；SenseVoice 需要下述原生辅助程序。
- `Cmd/Ctrl+1…9` 切换前九个页面；`Cmd/Ctrl+O` 按当前页面打开/导入文件，`Cmd/Ctrl+J` 切换 AI 侧栏，`Cmd/Ctrl+Enter` 发送问题，`Cmd/Ctrl+N` 新会话，`Cmd/Ctrl+←/→` 上一项/下一项（PDF 为翻页）。页面获得焦点后空格翻面/播放，方向键切卡，视频左右键切换字幕句、音频左右键前后跳转，`1/2/3` 评分。输入框编辑时不拦截无修饰键的输入。

视频页收起学习助手、关闭播放器菜单或点击播放／定位／逐句重复等控件后，会将键盘操作交回视频，无需再次点击画面。左右键继续切句，空格播放／暂停；正在编辑问题、使用中文输入法或操作弹出菜单／对话框时，保留其自身键盘行为，字幕选区的复制焦点也保留。

## 字幕拖选复制

普通音频字幕列表、当前句卡片和视频字幕列表支持从文字上按住左键拖动选择，英文和中文可按字符选取，也可跨词、跨行或跨字幕句选择。选中后按 `Cmd/Ctrl+C`，或点击工具栏“复制选中”，只复制所选原文/译文，不混入时间戳、A/B 标签或操作按钮；`Esc` 清除选择。

普通单击仍用于定位播放，截取模式仍使用点击/Shift 点击选片段；右键下划线继续管理收藏。开始拖选后会暂停播放和自动跟随，避免切句或松开鼠标触发定位；已有 A/B 边界和收藏下划线保留。切换材料、切页、重新载入不同字幕或进入盲听时清除选区；盲听隐藏文字不参与拖选复制。字幕复制使用独立焦点，不接管输入框的复制快捷键。长列表可配合滚轮继续选择，暂未实现拖至滚动区边缘自动滚动。

默认 E2E 收集真实 SQLite/SRT 的纯文本与 UTF-8 选区映射，可用 `--subtitle-selection-only` 定向复验，保留选中 TXT 和 JSON；这不代替原生窗口鼠标及剪贴板交互验收。

## 冥想与计时提示音

计时状态保存在本机资料库，不进入云端／ZIP 备份。恢复已到期的一轮与完成统计使用同一事务，重复打开不会重复统计；保存失败会提示并保留原状态。可用 `--focus-timer-only` 定向运行跨进程、暂停继续、离线到期、事务失败和损坏记录恢复 E2E，默认完整 E2E 同时收集，保留 SQLite 和 JSON 证据。

冥想页与全局专注计时器共用提示音：点击“开始”或选择时长启动新一轮时播放一声轻柔铃音，每轮专注/休息结束时播放两声。暂停和继续不重复播放开始音，重置会停止尚在播放的提示音；切换学习模块后仍按时提醒。提示音使用独立播放器，不打断学习音频或背景音乐，音量独立于学习播放器的静音与音量，仍受系统输出设备和系统音量控制。

铃音在本机合成并缓存，无需下载或额外的声音资源打包。播放失败会提示错误，计时继续运行。默认 E2E 收集 WAV 生成、libmpv 独立解码与缓存恢复；可用 `--timer-chimes-only` 定向复验，保留两种 WAV 与 JSON。仅在本机需要验证默认声卡输出时使用 `--timer-chimes-audible`（会实际发声），不纳入默认无声测试；声卡初始化和解码通过也不代表已由人工确认听感。

## 截取片段的 A/B 标记

开启音频“截取片段”后，字幕列表和当前句卡片的选区也显示竖线：蓝色 `A ▶` 为起点，紫红色 `◀ B` 为终点，与音轨和进度条保持同色。A 标签在词语上方、B 标签在下方，同词内的短选区也能区分；标记锚定词语，换行时一起移动。拖动音轨边界会同步更新字幕标记；落在字幕间隙的边界显示在选中原文内侧，无原文覆盖的纯间隙不显示字幕竖线。词内位置沿用现有字符时间估算，不代表声学对齐。清除范围或退出截取后移除字幕边界，收藏下划线保留。

## 字幕中的收藏片段

音频字幕列表、当前句卡片及视频字幕列表中，已经存为片段闪卡的原文显示绿色下划线。右键下划线查看对应片段，再点“取消收藏复习”，会一起移除该闪卡、复习计划及收藏记录，保留原媒体、导出的片段文件和字幕。重叠片段分别列出，只取消选中的那一个。左键点击字幕词语（含已收藏的词语）仍用于定位播放，当前句卡片沿用同一操作；音频截取模式或 Shift 点击仍按原规则选取新片段，盲听不会显示收藏下划线或隐藏原文。

新保存的片段记录来源和原始时间范围，跨句、修改卡片原文和重启后仍可标记；资料备份恢复时会重定位来源。旧片段优先使用原媒体及时间，缺少来源的导出片段尝试按当前文稿中唯一匹配的完整原文定位，忽略大小写及标点差异。重复原文或已改写而无法匹配时不标记；旧数据无法可靠区分不同材料中完全相同的原文，可右键标记后核对片段。

## 音频整组字幕

音频管理中，当前练习组的标题下方提供“整组生成英文字幕”和“整组翻译中文字幕”。处理开始时全组的音频，不受搜索、筛选或之后切换组影响；新加入的音频留到下次处理。

生成英文时，已有有效英文字幕的音频自动跳过。翻译中文时，只发送缺少中文的句子，保留已有中文；没有英文字幕的音频会先自动转写英文，再翻译。使用设置中的转写和聊天服务，逐条显示进度；单条失败继续处理其它音频。可在顶部取消，已保存的结果保留，再次运行会跳过已完成字幕。翻译失败时已生成的英文也会保留，重试无需重复转写。任务期间修改字幕、移动或删除音频后，迟到结果不会覆盖新内容。

## 提示与任务

页面不再保留底部常驻状态栏。复制、保存、载入等普通提示使用浮动通知，约 5 秒后消失；错误独立保留，可手动关闭，不被普通提示覆盖。可安全重复的刷新、字幕生成／翻译和打开文档提供重试，材料已切换时会要求在当前页面重新操作，避免误处理新材料。

通用任务进度、模型下载百分比和取消按钮位于顶部任务提示区域；字幕队列和聊天、写作已有的专属状态继续保留。音频字幕生成或翻译完成会自动载入，不再提示手动刷新。

## 写作练习

侧栏“写作练习”可新建多篇写作，分别保存可选标题、题目与作答。题目和作答使用独立多行编辑器，题目区高 220px、作答区高 440px，支持回车换段、自动折行与内部滚动。输入后自动保存，也可手动保存；切换篇目或模块前保存当前草稿，重启后继续编辑。空白新稿不占用列表，保存失败保留编辑内容并显示错误。题目最多 30,000 字符、作答最多 60,000 字符，超出时不会截断正文。

点击“AI 批改”会先保存草稿，再将该次题目与作答一起发送给设置中的聊天模型，使用共用 API 地址、模型和密钥。反馈涵盖切题、结构、语法用词、具体修改建议与参考润色稿；题目没有评分标准时不要求模型编造考试分数。批改可取消，切换模块后仍可继续；失败、截断或取消不会新增成功批改。

每次成功批改独立保留，并保存当次题目和作答快照。之后修改草稿不会改变旧记录；批改期间继续编辑也不会被返回结果覆盖。历史意见以 Markdown 显示，可对照对应原文。删除写作需再次确认，并一并删除其批改历史。写作与历史均保存在本机 SQLite 的资料记录中，纳入现有 ZIP 与云备份，不包含 AI 密钥。

## 音频管理工作台

“音频管理”采用练习组、紧凑音频列表和所选详情的布局；大窗口显示练习组侧栏，普通窗口用可搜索的组菜单，窄窗口堆叠内容。练习组显示音频数量并记住所选组。单击列表行只查看详情；双击音频名称后直接在原位置编辑，预填并选中当前名称，Enter 或行内“保存”确认，Esc 或“取消”放弃。音频改名不再打开右侧表单，原“重命名”按钮也使用同一行内编辑器。名称校验失败保留输入；切换条目、练习组或模块时取消未确认的改名。点击“开始学习”才播放。“查看 / 管理字幕”打开学习页并暂停，可在顶部工具栏生成字幕、翻译成中文，或从“更多”导入字幕。详情预览前五句字幕，并显示音频文件位置与缺失提示。

列表支持组内名称搜索、全部/附字幕/待配字幕筛选、最近/最早添加及名称排序。“附字幕”指字幕附件文件存在，详情进一步解析实际内容。导入音频与文字转音频位于顶部；TTS 编辑区按需打开，保留当前会话中的输入，不会长期挡住列表。新建组与练习组重命名使用独立表单；新建组默认填入本机当天日期（如 `2026-10-23`），同日重名时依次加上 ` (2)`、` (3)`，可修改后再保存；重命名预填所选名称。同组同名音频与同名练习组会提示换名。

“多选”可全选当前搜索筛选结果、移动到其他组、合并或移除记录；切换练习组清空勾选，移动遇到同名冲突时整批回滚，字幕与媒体引用随音频保留。移除前显示记录名称并确认，只删除库记录，附件文件保留。后台任务执行时禁用修改操作；切组不改变已经启动的导入/TTS任务目标，原生文件选择期间切组会要求重新导入。“更多导入”保留本机导入命令入口。

## 桌面导入悬浮窗

点击页面右上角“悬浮窗”，或按 `Cmd/Ctrl+Shift+I`，打开 232×60 的置顶胶囊；也可通过原生“AI”菜单显示或隐藏。拖动左侧叶子图标移动窗口，当前练习组切换或改名后同步，长名称截断并可悬停查看全文，点击组名返回音频管理。右侧圆形按钮导入，任务进行时变为取消；未配置命令时显示设置入口。“更多”将实际窗口展开为 232×148，显示详细状态、主窗口、设置及隐藏操作。`Esc` 先收起详情，再隐藏。隐藏不退出应用，也不取消已启动的导入，重启会恢复上次显示状态；关闭主窗口时随应用退出。

在“设置 → 悬浮窗与命令导入”保存本机命令，然后点击悬浮窗“命令导入音频”。命令应每行输出一个音频文件的完整路径；macOS通过zsh、Windows通过PowerShell执行，最长60秒。导入固定到点击时的组，之后切换模块或组不会更改目标。执行期间防止重复启动，提供取消及完成/失败提示；空命令提供设置入口，空库需先新建组。设置命令不依赖AI服务配置。

悬浮窗显示时，命令导入成功会在其下方打开小型命名面板，预填当前名称，直接编辑后按 Enter 或“保存名称”确认；多条音频可用左右按钮逐条查看，“保存并下一条”继续命名。切换条目保留当前草稿，“稍后”或 Esc 关闭面板且保留已保存名称，其余音频仍使用原名；可从“更多 → 命名刚导入的音频”重开。名称为 1–120 字，空名、同组重名和已移动/删除的目标会报错并保留输入。改名固定到本次导入的音频及目标组，不受主窗口切组影响，也不改变媒体/字幕文件路径。关闭或隐藏悬浮窗同时关闭命名面板。主窗口或悬浮窗聚焦时，`Cmd/Ctrl+Shift+Enter` 可执行已保存的导入命令；命名面板打开期间先保存或关闭，再启动下一次命令导入。

真实shell、Unicode/空格/引号路径、目标组锁定、SQLite重开、重复导入、批量部分失败后的逐条命名、名称校验及移动/删除保护、空输入/无效组、非零退出和进程取消由默认E2E收集，也可使用`--command-import-only`定向复验，保留WAV、SQLite与JSON报告。窗口拖动、跨应用置顶、中文输入和Windows交互需另行实机验收。

## 本地文字转音频：Kokoro ONNX

在“音频管理”选择或新建练习组，找到“文字转音频 · Kokoro ONNX”。首次点击“下载中英模型”（约 334 MiB），完成后输入文字，选择中英文音色和 0.5–2.0 倍语速，点击“生成并保存音频”。文字最多 10,000 字；名称留空会自动命名。“试听 / 开始学习”打开生成结果，生成的 WAV 也会保存在音频库，可重命名、导出备份。音色与语速选择重启后保留，正文不发送到远端，不需要 API Key。

使用固定的 [sherpa-onnx Kokoro multi-lang v1.0](https://k2-fsa.github.io/sherpa/onnx/tts/all/Chinese-English/kokoro-multi-lang-v1_0.html)。音色菜单提供常用美式、英式和中文音色；不是音色克隆。首次下载联网，SHA-256 校验通过后才解压安装；之后生成全程离线。模型保存在资料目录 `models/kokoro-multi-lang-v1_0/`，模型包内许可证随模型保留。生成耗时取决于本机 CPU 和文字长度，可通过底部“取消任务”停止；切换页面后任务继续，结果保存到启动生成时选择的组，不自动开始播放。生成失败或取消不保存半成品。生成时按句合成并按每句真实采样长度保存 SRT，进入音频学习即可显示原文、逐句定位；原文随字幕附件保存。句级时间来自实际合成片段，单词时间仍沿用已有字符插值，不代表声学逐词对齐。此前版本生成的音频未保存原文，需在“音频学习→字幕→生成原文字幕”使用 ASR 补字幕，或用原文重新生成。

Kokoro 需要独立原生程序 `clarora-tts` 和启用 TTS 的 sherpa-onnx C API 运行库。**下载模型不会安装运行库。** macOS 开发环境已安装 sherpa-onnx 时可执行：

```sh
cmake -S clarora-gpui/native/tts -B clarora-gpui/target/tts -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=/path/to/sherpa-onnx
cmake --build clarora-gpui/target/tts --config Release
sh clarora-gpui/scripts/package-macos.sh
```

macOS CMake 构建会将对应 sherpa-onnx C API / ONNX Runtime 动态库复制到辅助程序旁，打包脚本将它们与 `target/tts/clarora-tts` 一起放入 `.app/Contents/MacOS/tools/`。必须使用启用 TTS 的运行库，文件名含 `no-tts` 的发行包无法生成语音；若本机默认运行库仅用于 ASR，可用 `-DSHERPA_LIBRARY=/absolute/tts-enabled/lib/libsherpa-onnx-c-api.dylib` 显式指定。请同时提供与运行库版本匹配的头文件；二进制再分发需一并保留相关许可证。Windows 使用同一 CMake 项目与 MSVC，构建后将 `target/tts/Release/clarora-tts.exe` 和对应运行库放到桌面程序旁的 `tools/`；Windows 实机验证尚未完成。直接 `cargo run` 时将辅助程序目录加入 PATH。

运行默认 E2E 会检查输入校验、缺失模型、预取消；设置 `CLARORA_KOKORO_MODEL=/absolute/model-dir` 后额外实际生成中英文 WAV 和逐句 SRT，检查非静音、原文覆盖、连续时间、SQLite 重开、附件备份恢复及 libmpv 逐句定位，验证生成中取消清理。可额外设置 `CLARORA_KOKORO_ARCHIVE=/absolute/kokoro-multi-lang-v1_0.tar.bz2` 验证同一安装链的 SHA-256 / 安全解压。证据目录保留 `kokoro-english.wav`、`kokoro-chinese.wav` 和 `kokoro-evidence.json`。未配置模型时真实推理明确标记跳过。

## 端侧语音模型：名称、语言和运行要求

这里的“端侧模型”指 **ASR（语音识别）模型**，用于音频转写、视频字幕和跟读文本识别。模型文件下载后，本地转写不上传音轨；聊天、图片识字和 AI 点评仍调用设置中的远端 API。`engine=local` 使用下面的本地模型，`engine=compatible` 使用设置中保存的共用远端模型，两者的模型 ID 不可混用。

| 设置中的 ID | 实际模型 | 语言 | 参数量 / 下载体积 | 本地文件（相对资料目录） |
| --- | --- | --- | --- | --- |
| `tiny.en` | OpenAI Whisper Tiny.en | 仅英语 | 39M / 约 75 MiB | `models/ggml-tiny.en.bin` |
| `base.en` | OpenAI Whisper Base.en | 仅英语 | 74M / 约 142 MiB | `models/ggml-base.en.bin` |
| `small.en` | OpenAI Whisper Small.en | 仅英语 | 244M / 约 466 MiB | `models/ggml-small.en.bin` |
| `base` | OpenAI Whisper Base 多语言版 | 含中文、英语、日语等 | 74M / 约 142 MiB | `models/ggml-base.bin` |
| `small` | OpenAI Whisper Small 多语言版 | 含中文、英语、日语等 | 244M / 约 466 MiB | `models/ggml-small.bin` |
| `sense-voice` | FunAudioLLM SenseVoiceSmall，sherpa-onnx 2024-07-17 导出版 | 普通话、英语、日语、韩语、粤语 | INT8 ONNX，体积以实际文件为准 | `models/sense-voice/model.int8.onnx` 和 `tokens.txt` |

英语可从较小的 `tiny.en` 开始试用；中文 bilibili 视频使用 `base` / `small` 或 SenseVoice。`.en` 表示英语专用，不适用于中文。`base.en` 是首次配置的默认值，不会按视频语言自动换模型。更大版本的耗时和识别效果应在同一音轨上实测比较，表中体积不是最低内存要求，也不是本机速度测评。

Whisper 使用 [whisper.cpp 的 GGML 权重](https://huggingface.co/ggerganov/whisper.cpp/tree/main)，不是 PyTorch 权重；语言和参数说明见 [OpenAI Whisper](https://github.com/openai/whisper)，文件体积见 [whisper.cpp](https://github.com/ggml-org/whisper.cpp)。SenseVoice 固定下载 [2024-07-17 模型仓库](https://huggingface.co/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17/tree/main) 的 INT8 模型和词表；说明见 [sherpa-onnx 预训练模型](https://k2-fsa.github.io/sherpa/onnx/sense-voice/pretrained.html)。它不是后续的粤语微调版。下载先访问 Hugging Face，失败时尝试 hf-mirror.com。

设置页依次点击“下载模型”→“选用”→“保存 AI 与学习设置”。下载时显示当前文件的百分比、已下载/总 MiB、平均速度、来源和文件序号；来源未提供总大小时只显示已下载大小。SenseVoice 分别显示模型与词表的进度，百分比指当前文件。换源重试会重置该文件进度，切换页面后下载继续，底部持续显示进度；返回设置可查看完整面板（`Cmd/Ctrl+,` 打开设置）。只有主动取消或退出客户端才中止；取消可中断网络等待，只有校验并落盘后才报告完成。选用只将模型 ID 和 `local` 引擎填入表单，保存后才生效。“文件已下载”只检查文件存在，SenseVoice 必须同时有模型和词表；不表示推理运行库已安装或模型质量已验收。

两种模型都需要 FFmpeg 处理音轨。Whisper 使用 `clarora-asr`；未发现该辅助程序时回退到 `whisper-cli`。SenseVoice 必须使用带 sherpa-onnx 运行库的 `clarora-asr`，不能通过 `whisper-cli` 运行。当前原生辅助程序按 CPU 路径接入；下载模型不会自动安装这些工具。**已实际验证的是 macOS 的 Whisper tiny.en；其余五个模型只完成接入，尚未逐个实测，Windows 也未实机验证。**

原生转写辅助程序使用本仓库已有公开 C++ ASR 适配器，不依赖 React Native 运行时：

```sh
cmake -S clarora-gpui/native -B clarora-gpui/target/native -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=/path/to/whisper-and-sherpa
cmake --build clarora-gpui/target/native --config Release
```

需 `whisper.h`、`libwhisper`、GGML 头文件/库、`sherpa-onnx/c-api/c-api.h`、`sherpa-onnx-c-api` 及相应运行库。开发构建将产出的 `clarora-asr`（Windows 为 `.exe`）和运行依赖放在程序旁的 `tools/` 或 PATH。动态 GGML 的 CPU 后端也需提供；辅助程序优先寻找自身旁的 CPU 后端，开发环境可回退到编译路径或用 `CLARORA_GGML_CPU_BACKEND` 指定。完整分发包仅使用包内后端，忽略这些开发回退。

## bilibili 分P选集与自动续播

粘贴 BV / av 号或普通视频完整链接，点击“读取分P / 选集”获取标题、时长和完整顺序，再点击“视频选集”中的任意一集下载并播放。也可点击“识别并导入”，默认导入 P1；已有 `?p=` 的完整链接会导入指定集。分P列表与播放器“下一P”、列表“上一P / 下一P”均不需要手写参数；`Cmd/Ctrl+Shift+←/→` 也可切集。列表超过五行可滚动。

“自动下一P”默认开启，可随时关闭。当前集真正播放结束后自动准备下一集：已下载则直接播放，未下载则先下载；最后一集播完停止。单集循环或 A/B 循环优先，此时不会自动换集。失败或取消停止在当前集，可手动重试，不会循环重试下载。所有后台操作仍共用任务槽，转写等任务结束后才准备下一P。分P列表、当前集和已下载路径保存在 GPUI 本机资料中；重启恢复，删除的文件会重新下载。这里只识别同一 BV/av 视频的分P，不将合集里的不同 BV 视频合并成队列。

读取视频标题与分P使用 bilibili 的公开 `x/web-interface/view` 接口（BV/av参数），下载仍交给 yt-dlp，受视频可用性与来源限制。相关接口用法也可见 [yt-dlp 的 Bilibili 提取器](https://github.com/yt-dlp/yt-dlp/blob/master/yt_dlp/extractor/bilibili.py)。模型转写仍按每个实际视频文件独立保存字幕。

## 视频收藏与切换

“视频学习”右侧默认打开“我的视频”，显示所有已导入视频、当前选中项、来源和文件夹；播放器标题栏也有“切换收藏”菜单。可以一次选择多个本地视频，导入即收藏；bilibili 按同一来源只收藏一条视频，分P仅在“选集”中切换，下载其他P不会新增收藏卡片；卡片显示整条视频标题、总P数、已下载数量和上次选中P，并提供“查看选集”入口。旧收藏启动后在后台补齐来源标题；离线时优先显示已保存标题或下载文件名称，标题不随分P切换。已有分P收藏自动合并，保留所选P、文件和字幕缓存。重复导入同一文件会去重，同名但位于不同路径的文件分别保留，重启恢复收藏与上次选择。旧“最近打开”列表首次自动迁移，收藏不再按最近12条淘汰。

点击视频卡片或“选择播放”切换播放，已选视频可从头重播；“字幕 / 选集 / AI 提问”仍在相邻页签。“移除收藏”会弹出带背景遮罩的确认框，显示视频名称和红色“确认移除”按钮；取消或按 Esc 返回。确认后只移除收藏记录，视频文件和字幕缓存保留。移除当前视频会停止播放并清空当前画面、字幕和循环，等待选择其他视频；移除其他项不打断当前播放。文件已移动或删除时保留提示，仍可移除收藏。后台任务期间暂停切换/移除，先等待完成或取消任务。

每条收藏保存自己的 bilibili 选集信息，切回时恢复对应队列；本地视频不会沿用其他视频的自动下一P。新收藏保存在本机资料的设置中；此功能不代表已经完成跨设备备份/同步验收。

## 后台生成整组选集字幕

在“选集”或字幕工具栏点击“全部P生成字幕”，后台按顺序处理当前收藏来源的所有P：已有有效字幕直接跳过，未下载的P先下载再转写。单P失败会记录原因并继续后续P，结束显示生成、跳过、失败数量；再次运行可处理剩余项。当前视频“生成字幕／重新生成”也使用独立后台任务。

生成期间可以切换已下载P、下载并播放其他P或选择另一个收藏；后台不改变当前播放视频、所选页签或进度。前后台需要相同P时共享下载结果。新字幕只自动装载到当前仍在播放的对应视频，其余按文件保存，切回时读取。任务卡片显示已处理数量、当前P及提取/识别/保存阶段，“取消后台字幕”仅停止该队列，已完成字幕和下载文件保留。移除该收藏会取消其队列，后台结果不会重新创建已移除收藏；其他收藏的队列不受影响。

队列运行时暂不允许同时导入或翻译视频字幕，避免覆盖正在生成的结果；播放与分P切换仍可用。应用退出时停止未完成任务，不会在退出后继续运行；重启后可再次点击批量生成，已完成项会跳过。下载和模型依赖与单视频转写相同，批量处理未下载P会使用网络及磁盘空间。

## 视频转写与同步字幕

在“视频学习”打开已下载的 bilibili 视频或本地视频，在播放器右侧点击“生成视频字幕”（也可用 `Cmd/Ctrl+Shift+T`）。先在设置中下载并选择本地模型，或配置支持带时间轴转写的兼容接口。中文视频使用多语言 `base` / `small` 或 SenseVoice；`.en` 模型用于英语。

页面标题下方固定显示字幕任务卡片：生成视频字幕时显示提取音轨、语音识别、保存字幕三个实际阶段与已用时间；生成中文时显示已翻译段数。右侧提供大号“取消任务”，取消处理中禁用重复点击；完成、失败或取消后保留结果，可关闭提示。音频字幕生成/翻译和视频全屏使用同样的任务提示。没有真实百分比的语音识别只显示阶段，不估算进度。

程序提取音轨后生成 SRT，按视频文件路径、大小和修改时间绑定保存。重开同一文件自动恢复列表；替换或移动视频后需要重新生成。当前句随真实播放时钟高亮，暂停保留当前句，跳转和倒退重新定位；句间空白不高亮。列表采用虚拟化；开启“跟随”时按实际行高将当前句置于可视区域中间，首尾按可滚动范围定位，超长句从首行显示。可关闭“跟随播放”手动浏览，点击某句定位视频。每句右侧“复制”可复制完整正文，顶部“复制全部”按顺序复制所有字幕文字（不含时间戳），复制不改变播放状态；“导出 SRT”可保存完整字幕文件。

转写需要时间，任务区域可取消。本地临时音轨在结束/失败时清理；失败或取消不会用空结果覆盖原字幕。远端接口有自身上传大小限制，超限会报告失败；本轮未实现远端长视频自动切块。视频字幕会与对应视频一同进入新版资料备份，恢复后按新文件路径重建绑定；也可单独导出 SRT。

聊天的 JSON 响应、流式响应及非流式回退都要求明确正常结束（`finish_reason=stop`），流式还需结束标记；截断、过滤、未知完成状态、空白或超长回答不会保存为成功会话。缺失完成原因的接口会提示未确认完整生成。

云端备份列表、上传和恢复支持中断正在等待的请求；恢复在数据库提交前取消会回滚本轮合并并清理临时附件。备份清单开始发布后若取消或断线，远端可能已经保存，此时会提示“发布结果未确认”，需刷新云端列表核实；已收到成功响应或本机事务已提交则按完成处理。未发布清单的远端附件可能保留为无引用对象。

云备份上传在应用运行期间跨模块继续，切换栏目不会取消。页面顶部及视频全屏显示整理资料、上传附件、发布清单等阶段，以及已发送字节、服务端确认的附件数量、百分比和取消按钮；大附件采用分块传输，清单确认成功后才显示 100%。完成提示会保留到关闭或开始新任务，备份版本也加入设置页列表；读取列表时会明确提示版本数或当前前缀下暂无备份。此功能不包含退出应用后的继续上传。

本机 ZIP 与云备份共用 v2 格式及可选的书库扩展，包含原有卡片、音频、写作和会话、视频收藏、生成字幕、PDF／EPUB／TXT 书库，以及阅读位置、字号和播放位置。云备份中的 bilibili 原视频／分 P 只保存来源链接、标题和选集信息，不上传视频文件；字幕、学习进度及问答继续保留，恢复后显示“下载并播放”，点击才下载对应分 P，重新下载后延续原字幕与问答。没有来源链接的本地视频仍上传文件，已导出的独立音视频片段也保留。可用原文件的本机 ZIP 继续完整打包；尚未下载的链接收藏以链接备份。新策略仅作用于新备份，既有云端备份及视频对象不会自动删除。恢复会重定位附件、重建视频字幕和材料会话绑定；同内容书籍复用本机副本，保留本机已有进度和偏好。SQLite 表和设置从同一个只读快照收集，学习偏好使用明确白名单，密钥、凭证引用、云配置和本机命令不进入备份。仍支持没有扩展的旧 v2／原版基础资料；书库扩展需要新版 GPUI 才能完整恢复。本机 ZIP 导入／导出同样支持取消。

## 文档与电子书阅读

“文档阅读”支持 PDF、EPUB 2/3 和 TXT，点击“导入 PDF / EPUB / TXT”或按 `Cmd/Ctrl+O` 选择文件。导入后保存在本机书库，原文件移动后仍可阅读；同内容电子书重命名后再次导入会复用已保存副本。

PDF 保留原页面、目录、缩放与位置恢复。EPUB 按书籍的章节顺序重排文字，支持 EPUB 3 导航目录、EPUB 2 NCX 目录、章节内锚点、标题和常见包内位图；不执行书籍脚本或读取外部图片。复杂 CSS、固定版式、公式和 SVG 绘图不保证保留原样，不能将本实现视为完整 EPUB 标准符合性认证。加密／DRM 书籍、MOBI、AZW3 暂不支持。

电子书以阅读片段翻页，“上一段／下一段”及 `Cmd/Ctrl+←/→` 共用同一进度；目录点击定位相应片段。片段编号不对应原版纸书页码。`A−/A+` 或缩放快捷键调整字号，每本书分别保存片段位置和字号，重启恢复。正文可选取复制，也可复制整个当前片段；AI 助手只引用当前片段，与当前书籍会话关联。

TXT 支持 UTF-8（含 BOM）和带 BOM 的 UTF-16；其它编码请先转换。源文件上限 128 MiB，EPUB 单成员上限 16 MiB、解压合计 256 MiB，过大的插图会显示图片说明。EPUB/TXT 导入先完成解析，再保存副本；失败或取消保留原阅读内容，未接受的本轮新副本清理。书库文件与已有阅读进度纳入新版 ZIP／云备份，可恢复到另一个资料目录。

## 界面状态与数据读取

视频播放器顶部的“英文文稿”可展开播放器下方的整宽阅读区，连续查看当前视频的整篇英文字幕，支持选择文字、滚动阅读和“复制英文全文”。文稿隐藏时间轴及中文翻译，字幕换片、导入、生成或翻译完成后同步更新；没有独立英文行时会提示导入或生成字幕。中英混合在同一行的内容不纳入英文文稿。

`app_state.rs` 分别持有音频学习、视频学习、播放器、后台任务和设置状态；聊天由 `chat_store::State` 管理。助手、设置及记录页面渲染消费缓存，材料切换、保存、任务结束、恢复和手动刷新时才更新数据。聊天按材料 context 通过 SQLite 索引查询最多 12 条会话，避免每次重绘扫描并解析全部 AI 记录。请求身份同时校验材料、会话和代次，旧请求不能覆盖切换后的对话；草稿保存或读取失败时保留当前内容。

`view_data::State` 缓存跟读、OCR、统计、词条、PDF 书库、文件及模型状态，显式刷新失败保留上一次完整快照并显示错误。公共词汇关系数据在刷新时预加载并共享。播放器比较完整可见快照，包含初始化、错误、字幕、轨道与画面清空，暂停期间的变化同样触发重绘。

`audio_controller.rs`、`video_controller.rs`、`task_controller.rs` 与 `playback_controller.rs` 协调播放和任务；页面与音视频渲染分别放在 `pages_ui.rs`、`audio_player_ui.rs`、`video_player_ui.rs`，动作路由独立于渲染。`data_controller.rs` 只提交和接收资料请求，`library_controller` 用单个后台线程读取完整快照，合并未执行请求并只保留最新结果。页面、练习组、筛选、音频、字幕路径、管理选择及视频身份均参与校验，旧结果不会覆盖新材料。卡片仅在闪卡／发现页读取，发现页的字幕分段及下条推荐数据在后台准备；音频目录保留跨组管理语义。加载期间不播放或评分旧卡片，读取失败保留上次内容。

`chat_controller` 将会话读取、选择、刷新与草稿持久化交给专用串行线程；输入以 300ms 防抖合并，切材料先保留当前草稿，旧代次读取结果失效。失败保留输入并提示，重试有退避。正常关闭窗口、Cmd/Ctrl+Q 和退出菜单会异步确认草稿保存，等待期间仍保持窗口响应；系统强制终止无法保证尚未落盘的最后输入。


## 可复现验证

GPU 图片纹理按当前场景管理：视频换帧、离开视频／复习页、PDF 翻页和电子书插图更换时，从 GPUI 图集中释放旧纹理；暂停重绘复用当前图片。仅释放 Rust 图片引用不会清除 GPU 图集。

视频页的字幕工具区和选集页均提供“全部P翻译中文”：只读取已有英文字幕缓存，按选集顺序在后台生成双语字幕。任一句已有中文就跳过整个P，不请求模型；缺少英文字幕的P列出失败原因并继续，可先生成英文后重试。已恢复的B站来源即使尚未下载视频也可翻译已有英文缓存，不会为翻译下载视频。失败、取消或期间新导入字幕时保留原结果。

默认 E2E 收集真实窗口的 GPU 内存检查。在有图形会话的 macOS 上设置 `CLARORA_GUI_MEMORY_CHECK=1` 启用，也可运行 `CLARORA_GUI_MEMORY_CHECK=1 cargo run --locked --bin e2e -- /absolute/evidence --gpu-memory-only` 定向复验；macOS CI 默认启用。探针实际上传持续更换的图片，覆盖暂停、尺寸变化、隐藏和恢复，检查包含 GPU／压缩内存的 physical footprint，并保留 JSON 采样；超过内存上限会退出。未启用或非 macOS 环境明确标记跳过，不能用仅解码或 RSS 的检查代替。

默认 E2E 在同一图形开关下收集至少 32 秒真实 libmpv／GPUI／Metal 视频稳定性检查，输出每两秒的 physical footprint、CPU、绘制数、真实帧数和阶段变化。原生窗口隐藏且不抢焦点，独立驱动真实绘制／纹理上传，避免窗口遮挡造成系统 display link 停止；这不等于前台画面呈现、真实声卡或系统睡眠验收。每个阶段等待播放器确认后完整停留，暂停先等待画面稳定；测试按完整循环结束，实际时长可能超过请求值。可用 `CLARORA_GUI_MEMORY_CHECK=1 cargo run --locked --bin e2e -- /absolute/evidence --runtime-stability-only 7200` 延长至至少两小时；内存越界或采样停顿会失败，保留 JSON／JSONL。运行需要 macOS 原生图形会话。

默认 E2E 也收集后台资料、聊天草稿及全部P翻译的真实 SQLite／文件／HTTP 回归。可分别用 `--data-loader-only`、`--chat-controller-only`、`--video-batch-translation-only` 定向复验。调试构建在 macOS 图形开关启用时同时启动隐藏的真实应用，验证资料切换、盲听、InputState 草稿、会话重试以及关闭／全局退出保存，报告位于 `native-ui/`；可用 `--ui-controller-only` 单独运行，需先 `cargo build --bin clarora-gpui`。原生协调诊断仅编入调试版本，不操作用户正在运行的实例，也不代替真实键鼠及视觉验收。

全局助手由默认 E2E 收集，也可用 `--assistant-only` 复验，覆盖多轮选中文字的真实 HTTP 请求、选区快照、SQLite 重开、取消与截断失败、引用上限；保存请求及对话 JSON。原生协调诊断同时覆盖全局打开、跨栏目请求／草稿保留、失败可见、新对话和原材料历史恢复，并通过实际 InputState 选区和系统剪贴板检查非绘制回调、原文提取、引用固定、空选区及切页失效，防止松开鼠标时误用绘制接口而崩溃；这些检查不代替真实鼠标拖选及前台键鼠操作的实机验收。

收藏片段标记由默认 E2E 收集；可用 `--clip-marks-only /absolute/path/video.mp4` 定向复验真实 FFmpeg 导出、SQLite 原子保存／取消、跨句重叠与旧片段匹配、ZIP 恢复后的来源关联，输出 JSON、SQLite 和媒体文件证据。

整组音频字幕由默认 E2E 收集，可用 `--audio-batch-only` 定向复验。使用真实 SQLite、音频／字幕文件和本机 HTTP，覆盖语言跳过、部分中文补齐、英文自动生成、组快照、错误继续、取消、重试以及并发修改保护；保留 JSON 报告、请求记录和资料库。

英文文稿保存、重开、纯英文提取、HTML 转义、换片清空、重生成与长字幕完整性由默认 E2E 收集，可用 `--transcript-only` 定向复验，保留 SRT、纯英文 TXT、选区 HTML 和 JSON 报告。

完整书库备份由默认 E2E 收集，可用 `--backup-library-only /absolute/path/video.mp4` 定向复验；独立 SQLite、ZIP 和本机 HTTP 服务覆盖源目录移走后的书籍／视频／字幕／材料会话恢复，并输出 JSON 证据。视频渲染可用 `--video-render-only` 定向复验，保留真实 FFmpeg／libmpv 画面与渲染统计；完整 E2E 同时覆盖动态尺寸及原有三遍重复行为。原生窗口与实际声卡、Windows 仍需单独验收，不能用库级 E2E 代替。

cargo fmt --manifest-path clarora-gpui/Cargo.toml --check
cargo check --manifest-path clarora-gpui/Cargo.toml --locked --all-targets
PDFIUM_LIB_PATH=/absolute/path/containing/pdfium cargo run --manifest-path clarora-gpui/Cargo.toml --locked --bin e2e -- /absolute/path/to/evidence

写作保存、批改与备份场景由默认 E2E 收集，也可用 `cargo run --manifest-path clarora-gpui/Cargo.toml --locked --bin e2e -- /absolute/path/to/evidence --writing-only` 定向复验，证据保留在独立写作资料目录。

电子书由默认 E2E 收集，也可用 `--ebook-only` 定向复验真实 EPUB 2/3 ZIP、目录锚点、UTF-8/UTF-16、图像解码、导入去重、SQLite 进度重开、取消／坏包和本机 HTTP AI 请求。`--ebook-only /absolute/path/book.epub` 可额外检查指定真实书籍，报告保存标题、目录、首／中／末页及图片检查结果，不读取用户默认学习资料。

本句重复场景由默认 E2E 收集，也可用 `cargo run --manifest-path clarora-gpui/Cargo.toml --locked --bin e2e -- /absolute/path/to/evidence --video-repeat-only` 定向复验。使用真实 FFmpeg/libmpv 检查无限循环、每句三遍后自动下一句、快速左右切句保留三次、首尾边界、短句、重选、暂停继续、手动跳转和换片，保留逐步播放快照和解码帧。

默认 E2E 同时收集复习类型与限额、AI 完成校验、云备份取消三组回归场景。只复验这三组可执行 `cargo run --manifest-path clarora-gpui/Cargo.toml --locked --bin e2e -- /absolute/path/to/evidence --reliability-only`；同样生成 `e2e-report.json`，子目录保留队列、HTTP、取消耗时和 SQLite 前后状态证据。

聊天仓储、界面数据缓存和播放器状态变化也由默认 E2E 收集，可用 `--state-only` 定向复验，共 19 个场景／检查。覆盖大量无关及损坏 JSON 记录、索引查询、草稿故障保护、旧请求隔离、SQLite／配置／目录刷新失败、ZIP 恢复和真实媒体解码；保留 SQLite、JSON 报告和播放帧。2026-10-22 本机最终完整 E2E 的 40 条工作流全部通过，包含真实 Whisper tiny.en、Kokoro、PDFium 和后台字幕队列；本轮未重跑完整窗口操作或 Windows。

E2E 使用独立临时资料，经过真实 SQLite、文件、ZIP、FFmpeg、libmpv、PDFium 和本机 HTTP 服务，输出 `e2e-report.json`、播放帧与 PDF 图片。libmpv 使用 null 音频输出，供 CI 验证解码和时钟，不验证系统声卡。HTTP 用固定本机响应验证协议，不代表外部 AI 或云桶已通过。未设置 `PDFIUM_LIB_PATH` 时 PDF 检查会明确跳过。

2026-10-17 本机执行含真实 Whisper 的 17 条链路通过。HTTP 夹具额外覆盖中文跨块、CRLF/多行 SSE、推理字段、405 回退、401 不重试、缺少结束帧、错误帧、截断和响应等待取消；聊天、OCR、远端转写的等待取消测得约 171–185 ms。波形结果保存在 `waveform.json`。另经 macOS 界面验证三页 PDF 导入/翻页/重启、实际缩放和恢复，以及本机模拟接口的连续问答、材料隔离、草稿切换恢复和重启续聊；第三轮请求携带前两轮历史。PDF 页面改为后台解码后直接绘制，修复翻页/重启只恢复页码但内容空白的问题。这不是完整桌面 GUI、Windows 或独立 review 的通过结论。

可额外设置 `CLARORA_ASR_MODEL` 为已下载的 `ggml-tiny.en.bin`，`CLARORA_ASR_SPEECH` 为包含 “Hello … learning” 的英文语音文件，并将编译好的 `clarora-asr` 放入 PATH；E2E 会执行真实本地转写，输出 `offline-transcription.srt`。macOS 可用 `say -v Samantha -o speech.aiff 'Hello world. This is a simple English reading exercise. Keep learning every day.'` 生成相同语音夹具。

依赖入口：[GPUI](https://crates.io/crates/gpui)、[gpui-component](https://github.com/longbridge/gpui-component)、[libmpv](https://mpv.io/manual/stable/)、[yt-dlp](https://github.com/yt-dlp/yt-dlp)、[PDFium binaries](https://github.com/bblanchon/pdfium-binaries)。分发第三方运行库时需附带对应许可证。

本地 Whisper 通过 GPUI 原生辅助程序识别时，按超过一秒的低能量停顿分段，并将结果还原到原始时间轴，减少复述练习长停顿时的漏句和虚构内容；识别准确率仍取决于录音和模型。更新后已保存的字幕不会自动替换，可在对应 P 的字幕页点击“重新生成”，再生成中文翻译。
