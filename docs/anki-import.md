# Anki 卡组导入

Clarora 的 macOS 和 Windows 客户端，在「闪卡」页面点击 **Anki 导入**，选择 `.apkg`、`.colpkg`、`.txt` 或 `.tsv` 文件即可将文字笔记合并到现有闪卡。取消选择不会修改资料；导入失败会显示原因，可重新选择文件。

## 准备文件

在 Anki 桌面端导出时勾选 **支持旧版本（Support older Anki versions）**，再选择卡组包。当前读取 `collection.anki2` / `collection.anki21` 的兼容格式；遇到新版压缩 `collection.anki21b` 会要求重新导出，不导入包内的兼容性占位提示。参见 [Anki 官方导出说明](https://docs.ankiweb.net/exporting.html)。

## 导入范围

- 识别 Front/Back、正面/背面等字段；未识别时使用前两个字段。HTML 转为文字，填空标记还原为答案文字。
- 只导入有正面和背面文字的笔记；媒体占位符、图片、音频、模板样式、卡组层级与 Anki 学习排程不迁移。单字段或清理后缺文字的笔记跳过。
- 同名正面更新释义，已有词条及其学习进度保留；不会因为导入包缺少某张卡而删除现有卡片。重复导入不会增加同名词条。
- 导入数量是本次有效笔记的处理数，同一正面在包内重复出现时可能多次计数；最终仅保留一个同名词条。
- `.colpkg` 也仅合并文字笔记，不替换本机资料库。目标写入使用事务，失败回滚；源文件不修改，解包用的临时数据库在成功或失败后清理。

移动端不开放直接 Anki 导入，保持现有桌面导入后同步的方式。

## Anki 文本文件（.txt / .tsv）

支持 UTF-8（可带 BOM），未声明分隔符时默认 Tab。可读取 Anki 的 `#separator:`、`#html:`、`#columns:` 与 `#tags column:` / `#deck column:` / `#notetype column:` / `#guid column:` 文件头。分隔符支持 Tab、Comma、Semicolon、Space、Pipe、Colon 或对应字符；特殊列号从 1 开始。文件头位于数据之前。

```text
#separator:tab
#html:true
#tags column:3
#deck column:4
```

上述格式的数据行为「正面 Tab 背面 Tab 标签 Tab 牌组」。特殊列不作为卡片内容；其余列识别 Front/Back 等名称，未命名时取前两个普通字段。标签、牌组层级、笔记类型与 GUID 不迁移，仍按正面文字合并，同名正面跨牌组也会合并；导入后提示这一范围。

支持双引号包围字段、字段内换行/分隔符，以及用两个双引号表示一个双引号。忽略空行与记录开头的 `#` 注释（引号内的 `#` 保留）。`#html:true` 将 HTML 转成文字并保留段落；省略或设为 false 时保留普通文本中的尖括号和实体。

为防止字段错位，列数必须一致（包括空的标签/牌组列）；非法配置、特殊列冲突/越界、未闭合引号或列数不一致均会在写入前报错。单字段、空正面/背面跳过。文本只迁移内容，不包含媒体文件、模板或 Anki 学习进度。普通文本的「导入文件」入口规则不变，请从 **Anki 导入** 选择这类文件。
