# 句子闪卡

在「闪卡 → 学习选项」中选择「句子」，点击「添加句子」。原句必填，译文与笔记选填；保存后进入句子门类，参加现有计划复习，也可切换「自刷」查看所有句子。

正面显示原句，翻面显示译文和笔记。长句可滚动阅读；翻面后用「忘了 / 模糊 / 认识」评分，系统安排下次复习。未填译文和笔记时，背面提示回想句意与用法。取消添加会保留当前页面中的草稿，保存失败也保留输入。

句子使用独立存储，单词文本/目录/Anki 导入不会自动归类为句子，也不会删除句子。句子参加「全部」与「句子」复习，不混入「单词」；本次未扩展「随便学学」。句子删除后清除对应复习记录。

句子和复习进度纳入自有存储备份。新客户端可恢复没有句子表的旧备份。跨设备使用句子功能前应更新所有客户端；旧客户端不认识新表，不应通过旧客户端恢复后重新备份来迁移句子。
