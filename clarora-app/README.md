# Clarora

React Native 统一客户端：macOS、Windows、Android、iOS 共用 `App.tsx`、学习页面、自有存储备份和 SQLite 数据模型。

iOS 首版工程位于 `ios/`；Windows 工程位于 `windows/`，使用 React Native Windows 0.76.17，与现有 0.76 系列保持兼容。Windows 运行 `npm run windows`，打包运行 `npm run windows:build`。平台范围、原生依赖、签名及验证限制见 [平台构建说明](../docs/platform-builds.md)。

## 功能

### 统一学习界面
- 音频管理采用可搜索的练习组入口、音频列表和当前音频操作面板；支持名称搜索、待配字幕筛选及批量管理。开始学习和字幕操作直接可见，文件路径、模型与命令导入按需展开；窄窗口自动上下排列并可滚动。
- 各学习页面沿用「随便学学」的留白、圆角卡片与简洁标题，内容区限制阅读宽度，适配深浅色主题。
- 闪卡的分类、复习模式和导入入口集中在「学习选项」；字幕工具、历史记录、自有存储备份及高级设置按需展开。
- 闪卡随可用高度伸缩，音频管理工具在窄窗口自动换行。折叠操作不会清空正在填写的内容。

### 随便学学
- 单词卡、音频片段卡、AI 问答卡和完整音频中的字幕片段混合推荐，打开即开始；macOS 支持左右滑动与 ←/→ 方向键，Android 上滑下一条、下滑返回，也提供上一条/下一条按钮。
- 优先避开本轮已看内容，穿插不同内容类型；温习、探索、收藏内容按约 40/40/20 的偏好抽取，候选不足时自动补充。浏览和跳过不改变 SM-2 进度。
- 完整音频按时间轴字幕切段，优先在约 20 秒后的句末结束，最长 60 秒；不截断单条字幕。没有可用时间轴字幕的音频不参与自动切段。
- 音频自动播放，播完当前片段即停；下一条提前选择，音频使用独立播放器预加载，返回上一条会从片段开头播放。离开栏目或进入后台停止播放。
- 「我的收藏」保存于本机；收藏自动抽取的音频片段时，也会去重写入普通音频闪卡库，可通过已有资料同步流程同步该闪卡。取消收藏不会删除已生成的闪卡。
- Android 展开长原文/答案后，上下滑动用于阅读；收起后恢复切换，也可直接点下一条。
- 本功能增加了原生音频预加载播放器，首次使用需重新构建客户端，单独刷新 Metro 不足以加载原生模块。

验证：`npm run typecheck`，`node --test tests/discover.test.cjs`。

### AI 学习助手（全局）
- 全 App 使用同一个 AI 助手入口：音频学习页放在顶部工具栏，其余页面放在右下方独立区域。打开时自动引用当前学习内容；没有材料时可自由提问。
- 桌面为右侧面板，窄屏为全宽面板。引用可展开查看和重新选取；底部输入框支持多行输入，点击「发送」，首问与追问共用一个输入框。
- 提供解释、语法、自测等问题建议；回答支持 Markdown、复制和存为 AI 问答闪卡。
- 回答走用户配置的 `/chat/completions` SSE 流式接口：思考过程实时流式显示（可折叠），答案边生成边渲染；兼容端点不支持流式路径时回退普通请求。
- 最近 12 个对话保存在本机，每个保留最近 30 轮问答和草稿。不同引用各自保留对话；「历史」切换，「新对话」开始自由提问。
- 请求失败或取消时保留问题，重新发送即可重试；旧请求不会污染切换后的对话。打开面板时暂停学习快捷键。

### 闪卡速记（首页）
- 📖 点击翻转查看单词/释义，左右滑动切换
- 🖥️ macOS 卡片背面支持触控板、鼠标滚轮和 ↑/↓ 键滚动，背面文字可直接选取并用右键或 ⌘C 复制
- 💬 **AI 学习助手**：点击右下角「✦ AI 助手」，当前已展示的文字自动成为引用；直接提问，或展开引用后拖选更小的片段。关闭面板后继续复习原卡片。
- 📁 **导入目录**：以目录为唯一来源，**整体替换**卡组 —— 在目录里删掉已学会的单词后重新导入，它们也会从 app 里消失
- 📄 导入文本文件（Tab、逗号、中文逗号、` - `、` : ` 等分隔符）
- ⭐ **听力片段卡**：听力页截取片段后可收藏为闪卡，复习时自动播放该段音频（英文正面 / 中文背面）
- 🔁 **SM-2 计划复习**：到期卡优先、新卡每日限量（默认 20，设置 `new_cards_per_day` 可调）；翻面后按 忘了/模糊/认识 评分（Mac 支持 1/2/3 键），「忘了」当次再练；目录重导入保留单词进度，调度随同步在两端互通；「自刷」模式保留随机浏览
- 🤖 **AI 问答卡**：听力页选中字幕向 AI 提问，回答面板点「存为卡片」收进复习队列（正面是问题 + 所选原文，背面是完整回答）；卡片随同步在两端复习

### 音频学习
- 紧凑播放器布局：顶部集中练习组、音频切换、字幕设置与 AI 助手；底部保留进度条和播放工具，倍速按需展开，窄屏工具可横向滚动。全文字幕占据主要空间，当前句卡片可在「字幕」设置中开启。
- 学习页字幕工具栏显示当前语言状态；仅有英文时可直接「生成中文字幕」。支持分别导入英文/中文 SRT、VTT，按时间轴合并并保留另一种语言，导入后在当前页立即显示。
- 🎯 **专注模式**：进入学习后隐藏全局栏目和全部管理按钮，仅保留音频选择、字幕、播放、倍速与片段截取
- 🎧 音频 + 字幕逐句跟读：点击单词跳转播放、自动高亮当前句/词
- 🤖 **AI 标重点**：点「✦ 标重点」把整篇转写发给 AI，重点词汇/短语在字幕里以琥珀色下划线标出，重点面板点击任意一条跳到对应句子播放
- 💬 **AI 学习助手**：选中字幕右键「向 AI 提问」或点「✦ AI 助手」，与闪卡、随便学学、识字和跟读页共用同一个聊天面板。
- 🎙 **跟读打分**：点「🎤 跟读」录下当前句的朗读（自动暂停播放），用户配置的 API 转写后在本机对齐后给出完整度 / 准确度 / 语速、漏读读错多读词汇与教练点评；记录保存在本机，可通过存储备份合并
- 🎚 0.6x / 0.7x / 0.8x / 1.0x / 1.2x 变速
- 📄 字幕支持 SRT / VTT / TXT（TXT 按行估算时间轴）
- 🔗 **组循环连播**：循环模式切到「组循环」后，一篇播完自动无缝接播组内下一篇
- ⏭ **单次连播**：循环再切一档，「单次连播」整组按顺序过一遍，播完最后一篇自动停止

### 音频管理
- 🗂 独立栏目集中管理练习组、音频增删改、批量操作和本地字幕
- 🏷 **双语字幕标识**：音频列表按字幕内容标注「双语字幕 / 中文字幕 / 仅原文」，可按双语筛选；当前音频面板同步显示字幕形态
- 🔀 **合并音频（仅 macOS）**：批量勾选 ≥2 个音频合并成一篇新音频（AVFoundation 重编码为 M4A，混格式/混采样率均可），各音频字幕按真实时长顺延后合成一份 SRT；原音频保留，合并结果随同步下发 Android
- 🤖 **AI 字幕**：直连用户配置的转写 API 生成字幕
- 🀄 **译中字**：把当前字幕翻译成中文；使用设置中的自定义兼容 API 与模型
- 🖥 **命令导入（仅 macOS）**：在 app 本机执行配置好的 shell 命令，把输出行当作音频路径导入练习组

### 冥想与番茄钟
- 🧘 自定义冥想时长与背景音乐
- 🍅 学习番茄钟支持 25/45/60 分钟专注、5/10/15 分钟休息，自动循环并统计完成轮数

#### 命令导入示例（仅 macOS）

用户可在 **设置 → 本机命令导入** 里配置命令，例如列出某个目录下的音频文件：

```bash
find ~/Music -maxdepth 2 -name "*.mp3"
```

然后在听力页选中练习组，点「命令导入」：
- 命令在 **app 本机** 执行（不经过 Clarora 服务器），输出的每一行当作音频路径
- 自动过滤音频扩展名（`.mp3 .m4a .wav .aac .aiff .flac .ogg .mp4 .mov`）与已删除文件
- 音频名取文件名（去扩展名），重名自动跳过

> ⚠️ 该功能需要 App Sandbox 保持关闭（`macos/Clarora-macOS/Clarora.entitlements` 中
> `com.apple.security.app-sandbox` 为 `false`）：沙盒应用禁止启动子进程，也无法读取
> `/Applications/...` 这类外部路径。此构建配置用于直接分发的 macOS 客户端。

## 快速开始

前置：Node.js 24、Xcode、CocoaPods；macOS 视频需要 libmpv（当前查找 /opt/homebrew）。

```bash
cd clarora-app
npm install

# 启动 Metro（保持运行）
npm start

# 另开终端，构建并启动 macOS 应用
npm run macos
```

修改原生 macOS 代码（如 `macos/Clarora-macOS/AppDelegate.mm`）后，需要再次运行
`npm run macos` 重新构建。仅修改 JS/TS 时，保持 Metro 运行并在其终端按 `r` 刷新即可。

`npm run macos` 和 `npm run macos:release` 会在 Pods 缺失或依赖锁文件不一致时自动安装 CocoaPods 依赖。修改 Podfile 后执行 `npm run macos:pods`。如果提示缺少 `Pods-Clarora-macOS.debug.xcconfig`，也可用此命令重新生成；不要从其他项目复制 Pods。

### Android

前置：Android Studio、Android SDK（API 35 或以上）、JDK 17，以及已启动的 Android 模拟器或已连接的真机。

```bash
cd clarora-app
npm install

# 启动 Metro（保持运行）
npm start

# 另开终端，构建并安装 Debug 客户端
npm run android
```

也可以只生成 APK：`npm run android:apk`，产物位于
`android/app/build/outputs/apk/debug/app-debug.apk`。

Android 使用系统文件选择器导入音频/字幕、支持音频播放和变速；字幕长按可复制。macOS 的本地 shell
命令导入及原生字幕右键“问 AI”菜单不在 Android 端显示。

### 自有存储同步与备份

四个平台使用相同的对象存储适配：设置中配置自己的 S3 兼容存储或阿里云 OSS，备份本机资料后，在另一台设备读取版本并合并。没有 Clarora 账号或服务端依赖。当前为手动全量版本备份，不传播删除，本机已有内容优先。详细数据范围、冲突规则及凭证存储限制见 [同步说明](../docs/storage-sync.md)。

AI 在「设置 → AI 服务」配置 API 地址、密钥与模型，聊天/翻译使用兼容 Chat Completions 协议，OCR 配置视觉模型，转写配置支持 verbose_json 时间轴的模型。OCR 与跟读结果保存在本机，可随资料备份。

## 项目结构

```
clarora-app/
├── shared/              # macOS、Android 共用的 React Native 代码
│   ├── screens/         # 页面：闪卡、听力、设置、图谱、冥想
│   ├── data/            # SQLite、导入和字幕解析
│   ├── services/        # 对象存储、AI API 与平台原生桥接
│   ├── ui/              # 主题、上下文与 Markdown 渲染
│   └── types.d.ts       # 共享类型声明
├── macos/
│   └── Clarora-macOS/
│       ├── AppDelegate.mm   # 原生模块：RNFilePicker / RNMacAudio / RNShell
│       └── Clarora.entitlements
├── android/
│   └── app/src/main/java/  # Android 应用及文件、音频原生桥接
└── package.json
```

## 导入格式

文本文件每行一个单词，支持以下分隔符：

```
word\tmeaning
word,meaning
word，释义
word - meaning
word : meaning
word：释义
```

以 `#` 开头的行和空行会被忽略。
